[Description]
Pakko は、.NET 自体の圧縮 API だけを基盤に作られた、無料でオープンソースの Windows 用 ZIP アーカイバーです。7-Zip も WinRAR も使わず、アプリ内のどこにもサードパーティの圧縮コードはありません。

System.IO.Compression を通じて、パスワードの有無にかかわらず ZIP アーカイブを直接作成・展開できます。ZipCrypto と WinZip AES のアーカイブを開き、7-Zip などの ZIP ツールで読み取れる AES-256 暗号化アーカイブを作成します。RAR、7-Zip、TAR 系のアーカイブ (TAR、GZ、BZ2、XZ、ZST、LZMA) は Windows に標準搭載の tar.exe で読み取ります。tar.exe は、ネットワークにアクセスできない隔離された AppContainer サンドボックス内で実行されます。

Pakko はエクスプローラーに統合されます。右クリックで、展開、圧縮、アーカイブのテスト、お使いのウイルス対策ソフトによる脅威のスキャン、SHA-256 ハッシュの計算ができます。対応するアーカイブをダブルクリックすれば、すべてを展開しなくても中身を閲覧できます。展開されたファイルにはすべて、元のアーカイブの Mark-of-the-Web セキュリティ タグが引き継がれます。

自分のファイルを何が圧縮しているのかを正確に知りたい人のために作られています。ソースコードはすべて Apache 2.0 ライセンスのもと GitHub で公開されています。テレメトリなし、利用状況の分析なし、ネットワーク リクエストは一切ありません。インターフェイスは 37 の言語で利用できます。

[Short description]
.NET と Windows に組み込まれた圧縮コードだけを使う、無料でオープンソースのアーカイバーです。ZIP の作成と展開 (AES-256 パスワードにも対応)、サンドボックス内での RAR・7-Zip・TAR の展開ができ、エクスプローラーの右クリック メニューにコマンドを追加します。テレメトリはありません。

[Product features]
ZIP: .NET 自体の圧縮ライブラリによる作成と展開
パスワード付き ZIP: ZipCrypto と WinZip AES を開き、AES-256 で作成
TAR、GZ、BZ2、XZ、ZST、LZMA: Windows 標準搭載の tar.exe による展開と作成
RAR および 7-Zip: 展開のみ (Windows 標準搭載の tar.exe を使用)
エクスプローラーの右クリック メニュー: 開く、ここに展開、圧縮、アーカイブをテスト、脅威をスキャン、ハッシュ
アーカイブ ブラウザー: アーカイブの中を見て、画像やテキストをプレビューし、選択したものだけを展開
脅威をスキャン: インストール済みのウイルス対策ソフトがアーカイブの内容を検査
サンドボックス内での展開: RAR、7-Zip、TAR は、ネットワークにアクセスできない隔離された AppContainer 内で読み取られます
展開されたファイルは Mark-of-the-Web タグと元の日付を保持
コマンド ライン付属: 7-Zip 風のコマンドを備えた pakko コマンド
37 言語、ライト テーマとダーク テーマ
テレメトリなし、ネットワーク リクエストなし。オープンソース (Apache 2.0)

[What's new in this version]
• インストール直後から、どのターミナルでも pakko コマンドが使えます。スクリプト向けの 7-Zip 風コマンド ラインです。
• 展開したファイルとフォルダーに、アーカイブに保存されている日付が引き継がれます。
• アプリがキーボードでより操作しやすくなりました。「ファイルは既に存在します」のウィンドウに、両方のファイルのサイズと日付が表示されます。
• 最速の圧縮レベルで、圧縮済みのファイルが大きくなることがなくなりました。
• 英語以外の 36 言語すべてで翻訳を見直しました。エクスプローラーのメニューが Windows の言語リストに従うようになりました。
