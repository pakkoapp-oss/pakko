[Description]
Pakko は、.NET 自体の圧縮 API だけを基盤に作られた、無料でオープンソースの Windows 用 ZIP アーカイバーです。7-Zip も WinRAR も使わず、アプリ内のどこにもサードパーティの圧縮コードはありません。

System.IO.Compression を通じて、パスワードの有無にかかわらず ZIP アーカイブを直接作成・展開できます。ZipCrypto と WinZip AES のアーカイブを開き、7-Zip などの ZIP ツールで読み取れる AES-256 暗号化アーカイブを作成します。RAR、7-Zip、TAR 系のアーカイブ (TAR、GZ、BZ2、XZ、ZST、LZMA) と ISO、CAB、cpio、ar (.deb)、tar.Z、lzip は、Windows 自身のアーカイブ ライブラリ (標準搭載の tar.exe が使う archiveint.dll) で読み取ります。読み取りは、ネットワークにアクセスできない隔離された AppContainer サンドボックス内で行われます。 Windows に標準搭載の tar.exe で TAR 系と 7-Zip のアーカイブも作成できます (7-Zip はパスワードなし。tar.exe が 7-Zip を書き込める Windows のバージョンで利用できます)。

Pakko はエクスプローラーに統合されます。右クリックで、展開、圧縮、アーカイブのテスト、お使いのウイルス対策ソフトによる脅威のスキャン、SHA-256 ハッシュの計算ができます。対応するアーカイブをダブルクリックすれば、すべてを展開しなくても中身を閲覧できます。展開されたファイルにはすべて、元のアーカイブの Mark-of-the-Web セキュリティ タグが引き継がれます。

自分のファイルを何が圧縮しているのかを正確に知りたい人のために作られています。ソースコードはすべて Apache 2.0 ライセンスのもと GitHub で公開されています。テレメトリなし、利用状況の分析なし、ネットワーク リクエストは一切ありません。インターフェイスは 37 の言語で利用できます。

[Short description]
.NET と Windows に組み込まれた圧縮コードだけを使う、無料でオープンソースのアーカイバーです。ZIP (AES-256 パスワードにも対応)・7-Zip・TAR の作成と展開、RAR の展開ができ、アーカイブはサンドボックス内で読み取ります。テレメトリはありません。

[Product features]
ZIP: .NET 自体の圧縮ライブラリによる作成と展開
パスワード付き ZIP: ZipCrypto と WinZip AES を開き、AES-256 で作成
TAR、GZ、BZ2、XZ、ZST、LZMA: Windows 標準搭載の tar.exe による展開と作成
7-Zip: 展開と作成 (パスワードなし)、RAR・ISO・CAB・cpio・ar (.deb)・tar.Z・lzip: 展開のみ
エクスプローラーの右クリック メニュー: 開く、ここに展開、圧縮、アーカイブをテスト、脅威をスキャン、ハッシュ
アーカイブ ブラウザー: アーカイブの中を見て、画像やテキストをプレビューし、選択したものだけを展開
脅威をスキャン: インストール済みのウイルス対策ソフトがアーカイブの内容を検査
回復データ (PAR2): 新しいアーカイブに追加し、アーカイブを検証して、破損時に修復
サンドボックス内での展開: RAR、7-Zip、TAR は、ネットワークにアクセスできない隔離された AppContainer 内で読み取られます
展開されたファイルは Mark-of-the-Web タグと元の日付を保持
コマンド ライン付属: 7-Zip 風のコマンドを備えた pakko コマンド
37 言語、ライト テーマとダーク テーマ
テレメトリなし、ネットワーク リクエストなし。オープンソース (Apache 2.0)

[What's new in this version]
• 新機能: ISO、CAB、cpio、ar (.deb)、tar.Z、lzip のアーカイブを開いて展開・テストできます (読み取り専用。lzip は Windows 10 では非対応)。
• TAR、7-Zip、RAR のアーカイブは、サンドボックス内の小さな補助プログラムで Windows 自身のアーカイブ ライブラリを使って読み取るようになりました。どの言語のファイル名も保存されたとおりに届きます。
• 新機能: タスク バーのボタンと通知領域のアイコンに操作の進行状況が表示されます。
• 「脅威をスキャン」は、すべてのファイルを確認できなかった場合や、ウイルス対策ソフトが既知のテスト用脅威を報告しない場合に「何も見つかりません」と表示しなくなりました。
• 修正: 名前が空白またはピリオドで終わる TAR のフォルダー内のファイルが展開・スキャンされるようになりました。
• 修正: Windows の tar.exe がアーカイブを読み取る場合、システムの言語以外の名前が誤った名前で展開されることはなくなりました。
• 修正: 元のファイルをごみ箱へ移動するとき、一部がスキップされても全部を残すことはなくなり、残した項目にはそれぞれの理由が表示されます。
• 修正: キャンセルすると tar.exe がすぐに終了し、作業領域の小さいモニターにもウィンドウが再び収まります。
• 修正: アラビア語、ヘブライ語、ウルドゥー語、ヒンディー語など 12 の言語で、文字の切れや位置のずれを直しました。
