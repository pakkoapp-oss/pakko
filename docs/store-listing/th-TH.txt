[Description]
Pakko เป็นโปรแกรมบีบอัดไฟล์ ZIP แบบฟรีและโอเพนซอร์สสำหรับ Windows สร้างขึ้นทั้งหมดบน API การบีบอัดของ .NET เอง — ไม่มี 7-Zip ไม่มี WinRAR และไม่มีโค้ดการบีบอัดจากบุคคลที่สามในส่วนใดของแอป

สร้างและแตกไฟล์ ZIP ได้โดยตรงผ่าน System.IO.Compression ทั้งแบบมีและไม่มีรหัสผ่าน: Pakko เปิดไฟล์บีบอัด ZipCrypto และ WinZip AES ได้ และสร้างไฟล์บีบอัดที่เข้ารหัสด้วย AES-256 ซึ่ง 7-Zip และโปรแกรม ZIP อื่นๆ อ่านได้ ส่วนไฟล์ RAR, 7-Zip และไฟล์ตระกูล TAR (TAR, GZ, BZ2, XZ, ZST, LZMA) รวมถึง ISO, CAB, cpio, ar (.deb), tar.Z และ lzip จะอ่านด้วยไลบรารีไฟล์บีบอัดของ Windows เอง (archiveint.dll ที่ tar.exe ใน Windows ใช้อยู่) ภายในแซนด์บ็อกซ์ AppContainer ที่แยกออกมาและเข้าถึงเครือข่ายไม่ได้ tar.exe ที่มีอยู่ใน Windows ยังสร้างไฟล์บีบอัดตระกูล TAR และ 7-Zip ได้ด้วย (7-Zip แบบไม่มีรหัสผ่าน บน Windows รุ่นที่ tar.exe เขียนไฟล์ 7-Zip ได้)

Pakko ทำงานร่วมกับ File Explorer: คลิกขวาเพื่อแตกไฟล์ บีบอัด ทดสอบไฟล์บีบอัด สแกนหาภัยคุกคามด้วยโปรแกรมป้องกันไวรัสของคุณ หรือคำนวณแฮช SHA-256 และดับเบิลคลิกไฟล์บีบอัดที่รองรับเพื่อเรียกดูเนื้อหาโดยไม่ต้องแตกไฟล์ทั้งหมดก่อน ไฟล์ที่แตกออกมาทุกไฟล์จะยังคงมีแท็กความปลอดภัย Mark-of-the-Web ของไฟล์บีบอัดต้นทาง

สร้างขึ้นสำหรับทุกคนที่ต้องการเห็นอย่างชัดเจนว่าอะไรกำลังบีบอัดไฟล์ของตน — ซอร์สโค้ดทั้งหมดเปิดเผยต่อสาธารณะบน GitHub ภายใต้สัญญาอนุญาต Apache 2.0 ไม่มีการส่งข้อมูลการใช้งาน ไม่มีการวิเคราะห์การใช้งาน ไม่มีคำขอเครือข่ายใดๆ ทั้งสิ้น ส่วนติดต่อผู้ใช้มีให้ใช้ 37 ภาษา

[Short description]
โปรแกรมบีบอัดไฟล์แบบฟรีและโอเพนซอร์สที่ใช้เฉพาะโค้ดการบีบอัดที่มีอยู่ใน .NET และ Windows สร้างและแตกไฟล์ ZIP (รวมถึงแบบใส่รหัสผ่าน AES-256), 7-Zip และ TAR และแตกไฟล์ RAR โดยอ่านไฟล์บีบอัดในแซนด์บ็อกซ์ ไม่มีการส่งข้อมูลการใช้งาน

[Product features]
ZIP: สร้างและแตกไฟล์ด้วยไลบรารีการบีบอัดของ .NET เอง
ZIP แบบมีรหัสผ่าน: เปิด ZipCrypto และ WinZip AES ได้ สร้างแบบ AES-256 ได้
TAR, GZ, BZ2, XZ, ZST, LZMA: แตกไฟล์และสร้างผ่านเครื่องมือ tar.exe ที่มีอยู่ใน Windows
7-Zip: แตกไฟล์และสร้าง (ไม่มีรหัสผ่าน), RAR, ISO, CAB, cpio, ar (.deb), tar.Z, lzip: แตกไฟล์ได้อย่างเดียว
เมนูคลิกขวาของ File Explorer: เปิด, แตกไฟล์ที่นี่, บีบอัด, ทดสอบไฟล์บีบอัด, สแกนหาภัยคุกคาม, แฮช
ตัวเรียกดูไฟล์บีบอัด: ดูภายในไฟล์บีบอัด ดูตัวอย่างรูปภาพและข้อความ แตกเฉพาะไฟล์ที่เลือก
สแกนหาภัยคุกคาม: เนื้อหาของไฟล์บีบอัดจะถูกตรวจสอบโดยโปรแกรมป้องกันไวรัสที่ติดตั้งอยู่ในเครื่อง
ข้อมูลกู้คืน (PAR2): เพิ่มลงในไฟล์บีบอัดใหม่ ตรวจสอบไฟล์บีบอัด และซ่อมแซมหลังเกิดความเสียหาย
แตกไฟล์ในแซนด์บ็อกซ์: RAR, 7-Zip และ TAR จะถูกอ่านภายใน AppContainer ที่แยกออกมาและเข้าถึงเครือข่ายไม่ได้
ไฟล์ที่แตกออกมายังคงมีแท็ก Mark-of-the-Web และวันที่เดิม
มีบรรทัดคำสั่งมาให้: คำสั่ง pakko พร้อมคำสั่งแบบเดียวกับ 7-Zip
37 ภาษา ธีมสว่างและธีมมืด
ไม่มีการส่งข้อมูลการใช้งาน ไม่มีคำขอเครือข่าย โอเพนซอร์ส (Apache 2.0)

[What's new in this version]
• ใหม่: เปิด แตกไฟล์ และทดสอบไฟล์บีบอัด ISO, CAB, cpio, ar (.deb), tar.Z และ lzip ได้ (อ่านอย่างเดียว ไม่รองรับ lzip บน Windows 10)
• ตอนนี้ไฟล์บีบอัด TAR, 7-Zip และ RAR อ่านด้วยไลบรารีของ Windows เองในโปรแกรมช่วยขนาดเล็กภายในแซนด์บ็อกซ์ ชื่อไฟล์ทุกภาษาจึงตรงตามที่บันทึกไว้
• ใหม่: ปุ่มบนแถบงานและไอคอนในพื้นที่แจ้งเตือนแสดงความคืบหน้าของการทำงาน
• "สแกนหาภัยคุกคาม" ไม่รายงาน "ไม่พบสิ่งใด" อีกต่อไปเมื่อตรวจไม่ได้ครบทุกไฟล์ หรือเมื่อโปรแกรมป้องกันไวรัสไม่รายงานภัยคุกคามทดสอบที่รู้จัก
• แก้ไขแล้ว: ไฟล์ในโฟลเดอร์ TAR ที่ชื่อลงท้ายด้วยช่องว่างหรือจุดจะถูกแตกไฟล์และสแกน
• แก้ไขแล้ว: เมื่อ tar.exe ของ Windows อ่านไฟล์บีบอัด ชื่อที่อยู่นอกภาษาของระบบจะไม่ถูกแตกไฟล์ด้วยชื่อที่ผิดอีก
• แก้ไขแล้ว: การย้ายไฟล์ต้นฉบับไปยังถังรีไซเคิลจะไม่เก็บไว้ทั้งหมดอีกเมื่อข้ามไฟล์หนึ่งไป และรายการที่เก็บไว้แต่ละรายการมีเหตุผลของตัวเอง
• แก้ไขแล้ว: การยกเลิกจะหยุด tar.exe ทันที และหน้าต่างพอดีกับจอที่มีพื้นที่ทำงานเล็กกว่าอีกครั้ง
• แก้ไขแล้ว: ข้อความที่ถูกตัดหรือผิดตำแหน่งในภาษาอาหรับ ฮีบรู อูรดู ฮินดี และอีกแปดภาษา
