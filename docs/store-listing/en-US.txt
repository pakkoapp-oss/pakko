[Description]
Pakko is a free, open-source ZIP archiver for Windows built entirely on .NET's own compression APIs — no 7-Zip, no WinRAR, and no third-party compression code anywhere in the app.

Create and extract ZIP archives directly through System.IO.Compression, with or without a password: Pakko opens ZipCrypto and WinZip AES archives and creates AES-256 encrypted ones that 7-Zip and other ZIP tools can read. RAR, 7-Zip and TAR-family archives (TAR, GZ, BZ2, XZ, ZST, LZMA), as well as ISO, CAB, cpio, ar (.deb), tar.Z and lzip, are read with Windows' own archive library (archiveint.dll, the one behind its built-in tar.exe) inside an isolated AppContainer sandbox with no network access. Windows' built-in tar.exe also creates TAR-family and 7-Zip archives (7-Zip without a password, on Windows versions whose tar.exe can write it).

Pakko integrates natively with File Explorer: right-click to extract, compress, test an archive, scan it for threats with your antivirus or compute its SHA-256 hash, and double-click any supported archive to browse its contents without extracting everything first. Every extracted file keeps the Mark-of-the-Web security tag of the archive it came from.

Built for anyone who wants to see exactly what's compressing their files — the entire source code is public on GitHub under the Apache 2.0 license. No telemetry, no analytics, no network requests of any kind. The interface is available in 37 languages.

[Short description]
A free, open-source archiver that relies only on the compression code built into .NET and Windows. Creates and extracts ZIP (with AES-256 passwords too), 7-Zip and TAR, and extracts RAR; archives are read in a sandbox. No telemetry.

[Product features]
ZIP: create and extract with .NET's own compression library
Password-protected ZIP: opens ZipCrypto and WinZip AES, creates AES-256
TAR, GZ, BZ2, XZ, ZST, LZMA: extract and create, via Windows' built-in tar.exe
7-Zip: extract and create (without a password); RAR, ISO, CAB, cpio, ar (.deb), tar.Z, lzip: extract only
File Explorer right-click menu: Open, Extract here, Compress, Test archive, Scan for threats, Hash
Archive browser: look inside an archive, preview pictures and text, extract only what you select
Scan for threats: the archive's contents are checked by your installed antivirus
Recovery data (PAR2): add it to a new archive, verify the archive and repair it after damage
Sandboxed extraction: RAR, 7-Zip and TAR are read inside an isolated AppContainer with no network access
Extracted files keep the Mark-of-the-Web tag and their original dates
Command line included: the pakko command with 7-Zip-style commands
37 languages, light and dark theme
No telemetry, no network requests; open source (Apache 2.0)

[What's new in this version]
• New: ISO, CAB, cpio, ar (.deb), tar.Z and lzip archives open, extract and test (read-only; lzip not on Windows 10).
• TAR, 7-Zip and RAR archives are now read with Windows' own archive library in a small sandboxed helper: file names in any language arrive exactly as stored.
• New: the taskbar button and the tray icon show the progress of an operation.
• "Scan for threats" no longer reports "nothing found" when it could not check every file, or when the antivirus does not report known test threats.
• Fixed: files in TAR folders whose name ends in a space or a dot are extracted and scanned.
• Fixed: where Windows' tar.exe reads an archive, a name outside the system language is never extracted under a wrong name.
• Fixed: moving sources to the Recycle Bin no longer keeps them all when one source is skipped, and each kept item gets its own reason.
• Fixed: cancelling ends tar.exe at once, and the window fits again on a monitor with a smaller work area.
• Fixed: text that was cut off or misplaced in Arabic, Hebrew, Urdu, Hindi and eight other languages.
