[Description]
Pakko — безплатний ZIP-архіватор для Windows з відкритим кодом, побудований повністю на власних API стиснення .NET: без 7-Zip, без WinRAR і без жодного стороннього коду стиснення в застосунку.

Створюйте й видобувайте ZIP-архіви безпосередньо через System.IO.Compression, з паролем чи без: Pakko відкриває архіви ZipCrypto та WinZip AES і створює архіви із шифруванням AES-256, які читають 7-Zip та інші програми для ZIP. Архіви RAR, 7-Zip і родини TAR (TAR, GZ, BZ2, XZ, ZST, LZMA), а також ISO, CAB, cpio, ar (.deb), tar.Z і lzip читає власна бібліотека архівів Windows (archiveint.dll, на якій працює вбудований tar.exe) в ізольованій пісочниці AppContainer без доступу до мережі. Вбудований у Windows tar.exe створює також архіви родини TAR і 7-Zip (7-Zip без пароля, у тих версіях Windows, чий tar.exe уміє їх записувати).

Pakko вбудовується у Файловий провідник: клацніть правою кнопкою миші, щоб видобути файли, стиснути їх, протестувати архів, перевірити його на загрози антивірусом або обчислити хеш-суму SHA-256, а подвійним клацанням відкрийте будь-який підтримуваний архів і перегляньте його вміст, не видобуваючи все. Кожен видобутий файл зберігає мітку безпеки Mark-of-the-Web архіву, з якого його взято.

Створено для тих, хто хоче точно знати, що саме стискає їхні файли: увесь вихідний код відкритий на GitHub за ліцензією Apache 2.0. Жодної телеметрії, аналітики чи мережевих запитів. Інтерфейс доступний 37 мовами.

[Short description]
Безплатний архіватор із відкритим кодом, який покладається лише на код стиснення, вбудований у .NET і Windows. Створює й видобуває ZIP (зокрема з паролем AES-256), 7-Zip і TAR, а також видобуває RAR; архіви читає в пісочниці. Без телеметрії.
