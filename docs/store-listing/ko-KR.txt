[Description]
Pakko는 .NET 자체의 압축 API만을 기반으로 만든 Windows용 무료 오픈 소스 ZIP 압축 프로그램입니다. 7-Zip도, WinRAR도 없으며 앱 어디에도 타사 압축 코드가 없습니다.

System.IO.Compression을 통해 암호가 있든 없든 ZIP 압축 파일을 직접 만들고 풀 수 있습니다. Pakko는 ZipCrypto 및 WinZip AES 압축 파일을 열고, 7-Zip을 비롯한 다른 ZIP 프로그램에서 읽을 수 있는 AES-256 암호화 압축 파일을 만듭니다. RAR, 7-Zip, TAR 계열 압축 파일(TAR, GZ, BZ2, XZ, ZST, LZMA)과 ISO, CAB, cpio, ar(.deb), tar.Z, lzip은 Windows 자체 압축 파일 라이브러리(내장 tar.exe가 사용하는 archiveint.dll)로 읽으며, 네트워크에 접근할 수 없는 격리된 AppContainer 샌드박스 안에서 읽습니다. Windows에 내장된 tar.exe로 TAR 계열과 7-Zip 압축 파일도 만듭니다(7-Zip은 암호 없이, tar.exe가 7-Zip을 쓸 수 있는 Windows 버전에서).

Pakko는 파일 탐색기에 통합됩니다. 마우스 오른쪽 단추를 클릭하여 압축을 풀거나, 압축하거나, 압축 파일을 테스트하거나, 사용 중인 백신 프로그램으로 위협을 검사하거나, SHA-256 해시를 계산할 수 있고, 지원되는 압축 파일을 두 번 클릭하면 전체를 먼저 풀지 않고도 내용을 살펴볼 수 있습니다. 압축을 푼 모든 파일에는 원래 압축 파일의 Mark-of-the-Web 보안 태그가 그대로 유지됩니다.

자신의 파일을 무엇이 압축하는지 정확히 알고 싶은 모든 사람을 위해 만들었습니다. 전체 소스 코드는 Apache 2.0 라이선스에 따라 GitHub에 공개되어 있습니다. 원격 분석 없음, 사용 분석 없음, 어떤 종류의 네트워크 요청도 없습니다. 인터페이스는 37개 언어로 제공됩니다.

[Short description]
.NET과 Windows에 내장된 압축 코드만 사용하는 무료 오픈 소스 압축 프로그램입니다. ZIP(AES-256 암호 지원), 7-Zip, TAR 압축 파일을 만들고 풀며 RAR을 풉니다. 압축 파일은 샌드박스 안에서 읽습니다. 원격 분석이 없습니다.

[Product features]
ZIP: .NET 자체 압축 라이브러리로 만들기 및 압축 풀기
암호로 보호된 ZIP: ZipCrypto 및 WinZip AES 열기, AES-256으로 만들기
TAR, GZ, BZ2, XZ, ZST, LZMA: Windows 내장 tar.exe로 압축 풀기 및 만들기
7-Zip: 압축 풀기 및 만들기(암호 없음), RAR, ISO, CAB, cpio, ar(.deb), tar.Z, lzip: 압축 풀기 전용
파일 탐색기의 마우스 오른쪽 단추 메뉴: 열기, 여기에 압축 풀기, 압축, 압축 파일 테스트, 위협 검사, 해시
압축 파일 탐색기: 압축 파일 안을 살펴보고, 사진과 텍스트를 미리 보고, 선택한 항목만 압축 풀기
위협 검사: 설치된 백신 프로그램이 압축 파일의 내용을 검사
복구 데이터(PAR2): 새 압축 파일에 추가하고, 압축 파일을 검증하고, 손상되면 복구
샌드박스 압축 풀기: RAR, 7-Zip, TAR는 네트워크에 접근할 수 없는 격리된 AppContainer 안에서 읽습니다
압축을 푼 파일에 Mark-of-the-Web 태그와 원래 날짜 유지
명령줄 포함: 7-Zip 방식의 명령을 사용하는 pakko 명령
37개 언어, 밝은 테마와 어두운 테마
원격 분석 없음, 네트워크 요청 없음, 오픈 소스(Apache 2.0)

[What's new in this version]
• 새 기능: ISO, CAB, cpio, ar(.deb), tar.Z, lzip 압축 파일을 열고, 풀고, 테스트할 수 있습니다(읽기 전용, lzip은 Windows 10에서 지원되지 않음).
• 이제 TAR, 7-Zip, RAR 압축 파일은 샌드박스 안의 작은 도우미 프로그램에서 Windows 자체 라이브러리로 읽습니다. 모든 언어의 파일 이름이 저장된 그대로 표시됩니다.
• 새 기능: 작업 표시줄 단추와 알림 영역 아이콘에 작업 진행률이 표시됩니다.
• "위협 검사"는 모든 파일을 확인하지 못했거나 바이러스 백신이 알려진 테스트 위협을 보고하지 않으면 더 이상 "발견된 항목 없음"이라고 하지 않습니다.
• 수정: 이름이 공백이나 마침표로 끝나는 TAR 폴더 안의 파일을 압축 풀고 검사합니다.
• 수정: Windows의 tar.exe가 압축 파일을 읽을 때, 시스템 언어 밖의 이름이 잘못된 이름으로 풀리는 일이 없습니다.
• 수정: 원본을 휴지통으로 옮길 때 하나를 건너뛰어도 모두 남기지 않으며, 남긴 항목마다 이유를 따로 알려 줍니다.
• 수정: 취소하면 tar.exe가 즉시 종료되고, 작업 영역이 더 작은 모니터에서도 창이 다시 맞게 표시됩니다.
• 수정: 아랍어, 히브리어, 우르두어, 힌디어 및 다른 8개 언어에서 잘리거나 어긋난 텍스트.
