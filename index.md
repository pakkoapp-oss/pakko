# Pakko Developer Docs

This is the developer and API reference for [Pakko](https://pakkoapp-oss.github.io/pakko/) — a
minimal WinUI 3 ZIP/tar archiver for Windows built with no third-party compression code, using
only `System.IO.Compression` and Windows' own built-in `tar.exe`.

This site is generated from the project's own source and its checked-in documentation — the
same files anyone can read directly on [GitHub](https://github.com/pakkoapp-oss/pakko).

- **[Specification](docs/SPEC.md)** — product scope and the version roadmap
- **[Architecture](docs/ARCHITECTURE.md)** — layer diagram, DI wiring, current public signatures
- **[API Reference](api/index.md)** — generated from `Archiver.Core`'s and `Archiver.App.Core`'s
  own XML doc comments
- **[Security](SECURITY.md)** — threat model, CVE tables, mitigations
- **[Contributing](CONTRIBUTING.md)** — how to build and submit changes

Looking for the app itself? Get it from the
[Microsoft Store](https://apps.microsoft.com/detail/9p5mw010d8pr) or
[GitHub Releases](https://github.com/pakkoapp-oss/pakko/releases).
